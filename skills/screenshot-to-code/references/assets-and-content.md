# Assets and content

## Asset search order

1. Search the existing project by filenames, dimensions, file type, and visual preview.
2. Check installed icon libraries, font declarations, public/static folders, design tokens, and existing components.
3. Use source assets supplied alongside the screenshot.
4. Use a properly licensed external substitute only when permitted and attribution/license requirements are satisfied.
5. Generate a replacement only when the user authorizes generation and it will not impersonate a protected logo or misrepresent an exact match.
6. Otherwise use an isolated placeholder and disclose it.

Optimize new raster assets to sensible display dimensions and formats without visibly degrading them. Preserve transparency and focal crop. Provide meaningful alt text for informative images and empty alt text for decoration.

## Fonts

Use the exact local/project font when available. If the font is unknown, compare letterforms, x-height, width, weight range, and metrics before choosing a fallback. A similar-looking font with different width can destroy line wrapping; adjust the font choice before forcing widths or inserting manual line breaks.

Respect font licenses. Do not download or redistribute a commercial font without permission.

## Text and data

Transcribe readable visible text accurately. Mark uncertain characters rather than silently inventing them. Preserve realistic numbers, labels, and ordering where they influence layout. Do not bake text into images unless the source itself is artwork and accessibility is handled separately.

## Icons and logos

Prefer the exact supplied SVG or project asset. Do not substitute emoji for interface icons. Keep icon stroke/fill style and optical size consistent. Never approximate a recognizable brand mark and call it exact.
